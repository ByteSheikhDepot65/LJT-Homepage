# LJT-Homepage

Personal homepage of **Junteng Liu**, built with the [academicpages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

The site contains:

- **About** — personal details, education, research experience, skills, honors, publications, and contact information.
- **Publications** — full publication list.

## Local development

See the [academicpages documentation](https://github.com/academicpages/academicpages.github.io) for instructions on running the site locally.
